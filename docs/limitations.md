# 已知限制

这些是数据源或平台边界，不是待修的 bug。

## 数据新鲜度

- token 进出与请求数来自 `/alpha/usage/summary` 的批量聚合（2–3 分钟一批），可能略滞后；额度窗口、花费与重置时间取自实时端点。
- 账户级 API 不提供缓存命中 / 未命中的拆分，只给毛输入 token 总量；缓存命中数只出现在单次请求响应里，UI 插件看不到。

## 显示与入口

- 按钮只在**会话已开始**（发过至少一条消息）后出现；空白会话与欢迎页不渲染会话头部工具行。
- 跨计费周期时，若「已用」和「剩余」无法确认属于同一周期，卡片只显示绝对值与周期结束日，不给百分比。
- 官方调整额度上限后，卡片按实时读数跟随；只有偏离名义值在一定范围内时才继续显示档位表的名义值。

## 接口

- `/alpha/*` 是 Command Code 官方 CLI 自用的内部接口，不在公开 Provider API 文档里，字段名有变更风险；插件按「字段缺失即降级」处理。
- Windows 上用本地路径安装、且源码与 `$DSH_HOME` 不在同一块盘时，pnpm 会建出坏链接；改走 GitHub 安装或按 [Windows 注意事项](windows.md) 修复。
